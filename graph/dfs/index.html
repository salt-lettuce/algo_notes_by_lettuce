Depth-First Search (DFS)（深さ優先探索）

行けるところまで進んでから引き返す探索アルゴリズムについて解説します.

DFSについて

DFSは,今いる頂点の隣にまだ訪問していない頂点があればそこへ進み,進めなくなったら1つ前の頂点に戻って別の道を探す,という探索方法です.
迷路で「突き当たるまで進み,行き止まりなら分かれ道まで戻る」のと同じ動きで,再帰関数を使うと短く書けます.

代表的な使い道は次のとおりです.

  • ある頂点からある頂点へ到達できるかの判定,連結成分の分解
  • サイクル(閉路)の検出,トポロジカルソート
  • 木の部分木の大きさや深さなど,木の上での計算(木DP)
  • 全探索(順列や組合せを1つずつ作るバックトラック)

頂点数を N,辺の数を M とします.

操作計算量
1つの始点から到達できる頂点をすべて訪問$O(N + M)$
連結成分の分解$O(N + M)$

再帰による探索

DFSは次の関数 dfs(v) で表せます.

  1. v を訪問済みにする.
  2. v の隣の頂点 nv を順に見て,未訪問なら dfs(nv) を呼ぶ(そこから先を調べ終わるまで戻ってこない).
  3. 隣をすべて見終わったら,呼び出し元に戻る.

頂点 0 から始めたときの動きを1段階ずつ見てみます.頂点の横の数字は訪問した順番です.

同じグラフでもBFSでは 0 → 1, 2 → 3, 4 → … と近い順に広がっていましたが,DFSでは 0 → 1 → 2 → 4 → 5 → 3 と1本の道を深く進んでいきます.

行きがけ順と帰りがけ順

DFSでは,頂点を訪問したタイミング(行きがけ)と,その頂点から先をすべて調べ終わったタイミング(帰りがけ)の2つで処理を書けます.

  • 行きがけ順:上の図の番号の順.0, 1, 2, 4, 5, 3, 6
  • 帰りがけ順:調べ終わった順.3, 6, 5, 4, 2, 1, 0

木の上で「子の結果を使って親の値を決める」計算(部分木の大きさなど)は,帰りがけのタイミングで行います.
また,有向グラフ(サイクルなし)で帰りがけ順を逆にするとトポロジカル順序になります.

なぜ $O(N + M)$ なのか

dfs(v) は訪問済みの頂点に対しては呼ばれないので,各頂点について高々1回しか呼ばれません.
1回の呼び出しの中では v から出る辺を1回ずつ見るので,全体で $O(N + M)$ です.

実装

再帰関数で書くと次のようになります.上の図と同じグラフです.

import sys
sys.setrecursionlimit(10**6)

N = 7
edges = [(0, 1), (0, 2), (1, 2), (1, 3), (2, 4), (3, 5), (4, 5), (5, 6)]
G = [[] for _ in range(N)]
for u, v in edges:
    G[u].append(v)
    G[v].append(u)

visited = [False] * N
order = []  # 行きがけ順(訪問した順)
post = []   # 帰りがけ順(調べ終わった順)

def dfs(v):
    visited[v] = True
    order.append(v)
    for nv in G[v]:
        if not visited[nv]:
            dfs(nv)  # 行けるところまで進む
    post.append(v)  # ここに来たら v から先は調べ終わり

dfs(0)
print(order)
print(post)
[0, 1, 2, 4, 5, 3, 6]
[3, 6, 5, 4, 2, 1, 0]

注意点:再帰の深さ

  • Pythonの再帰の深さは標準で 1000 程度までなので,sys.setrecursionlimit で上限を上げておく必要があります.
  • 一直線のグラフのように再帰が深くなる場合,上限を上げてもPythonでは遅かったり,スタックが足りずに落ちたりすることがあります(PyPy では特に遅くなりやすい).
  • その場合は次のように,再帰を使わずスタック(リスト)で書きます.

スタックを使った実装

取り出したときに訪問済みなら飛ばし,隣の頂点を逆順に積むと,再帰と同じ行きがけ順になります.

N = 7
edges = [(0, 1), (0, 2), (1, 2), (1, 3), (2, 4), (3, 5), (4, 5), (5, 6)]
G = [[] for _ in range(N)]
for u, v in edges:
    G[u].append(v)
    G[v].append(u)

visited = [False] * N
order = []
stack = [0]
while stack:
    v = stack.pop()  # 末尾から取り出す
    if visited[v]:
        continue
    visited[v] = True
    order.append(v)
    for nv in reversed(G[v]):  # 逆順に積むと再帰と同じ順番になる
        if not visited[nv]:
            stack.append(nv)

print(order)
[0, 1, 2, 4, 5, 3, 6]

なお,この書き方では帰りがけのタイミングがわからないので,帰りがけ順が必要なときは「頂点 v を積む前に,v の帰りがけを表す印(例えば ~v)を積んでおく」などの工夫が必要です.

連結成分の分解

まだどの成分にも属していない頂点から探索を始め,たどり着いた頂点に同じ番号を付けていくと,グラフを連結成分に分けられます.
到達できる頂点を集めるだけなので,訪問の順番は気にしなくてよく,「積むときに印を付ける」簡単な書き方で十分です.

N = 8
edges = [(0, 1), (1, 2), (3, 4), (5, 6), (6, 7), (7, 5)]
G = [[] for _ in range(N)]
for u, v in edges:
    G[u].append(v)
    G[v].append(u)

comp = [-1] * N  # comp[v] : v が属する連結成分の番号
cnt = 0
for s in range(N):
    if comp[s] != -1:
        continue
    stack = [s]
    comp[s] = cnt
    while stack:
        v = stack.pop()
        for nv in G[v]:
            if comp[nv] == -1:
                comp[nv] = cnt
                stack.append(nv)
    cnt += 1

print(cnt)
print(comp)
3
[0, 0, 0, 1, 1, 2, 2, 2]

ライブラリでの実装

AtCoder Library (ACL) にはDFSのライブラリはありませんが,SciPy の scipy.sparse.csgraph にDFSの訪問順や連結成分を求める関数があります.

from scipy.sparse import csr_matrix
from scipy.sparse.csgraph import depth_first_order, connected_components

N = 7
edges = [(0, 1), (0, 2), (1, 2), (1, 3), (2, 4), (3, 5), (4, 5), (5, 6)]
row = [u for u, v in edges]
col = [v for u, v in edges]
G = csr_matrix(([1] * len(edges), (row, col)), shape=(N, N))

order, pred = depth_first_order(G, 0, directed=False)
print(order)
print(pred)

H = csr_matrix(([1] * 6, ([0, 1, 3, 5, 6, 7], [1, 2, 4, 6, 7, 5])), shape=(8, 8))
print(connected_components(H, directed=False))
[0 1 2 4 5 6 3]
[-9999     0     1     5     2     4     5]
(3, array([0, 0, 0, 1, 1, 2, 2, 2], dtype=int32))

depth_first_order の訪問順は内部の実装によって決まるので,自分で書いた再帰のDFSと一致するとは限りません(この例でも 6 と 3 の順番が違います).訪問の順番そのものが答えに関わる問題では自分で実装します.

操作一覧

操作操作内容計算量
depth_first_order(G, s, directed=True)s からDFSで訪問した順と,各頂点の1つ前の頂点を返す$O(N + M)$
connected_components(G, directed=True)連結成分の個数と,各頂点の成分番号を返す$O(N + M)$

BFSとの比較

BFSDFS
使う入れ物キュー(先入れ先出し)スタック(後入れ先出し)または再帰
訪問の順番始点に近い順行けるところまで進んでから戻る
重みなし最短距離求められる求められない
帰りがけの処理書きにくい自然に書ける
向いている問題最短距離・最短手数連結判定,サイクル検出,トポロジカルソート,木DP

到達できるかどうかや連結成分を調べるだけならどちらでもよく,最短距離ならBFS,帰りがけの処理や木の上の計算が必要ならDFSを使います.
