Bellman-Ford Algorithm（ベルマン-フォード法）

負の重みの辺を含むグラフで最短距離を求め,負閉路も検出できるアルゴリズムについて解説します.

ベルマン-フォード法について

ベルマン-フォード法は,「すべての辺について緩和(dist[u] + w < dist[v] なら dist[v] を更新)する」という操作を,更新が起きなくなるまでくり返す方法です.
ダイクストラ法より遅いですが,負の重みの辺があっても正しく動き,さらに負閉路(重みの和が負になるサイクル)があるかどうかも判定できます.

代表的な使い道は次のとおりです.

  • 負の重みの辺を含むグラフの最短距離
  • 負閉路の検出(負閉路を回り続けると距離をいくらでも小さくできる)
  • 得点を最大化する問題で,重みの符号を反転して最短距離の問題にしたもの

頂点数を N,辺の数を M とします.

操作計算量
1つの始点から全頂点への最短距離$O(NM)$
始点から到達できる負閉路があるかの判定$O(NM)$

すべての辺の緩和をくり返す

手順は次のとおりです.

  1. dist[始点] = 0,ほかは ∞ にする.
  2. すべての辺 (u, v, w) について,dist[u] + w < dist[v] なら dist[v] = dist[u] + w に更新する.これを1周とする.
  3. 1周の間に1回も更新が起きなければ終了.
  4. N 周目でも更新が起きたら,負閉路があると判定して終了.

次の有向グラフで,頂点 0 から1周ずつ見てみます.辺は (3→4), (1→3), (2→1), (0→2), (0→1), (2→4) の順に調べることにします.

なぜ N − 1 周で十分なのか

負閉路がなければ,最短経路は同じ頂点を2回通らないので,辺の本数は高々 N − 1 本です.
k 周目が終わった時点で,「辺を k 本以下使う経路の中での最短距離」は必ず求まっています(1周ごとに,最短経路の辺を少なくとも1本先まで正しく伸ばせるため).
したがって N − 1 周で全頂点の最短距離が求まり,それ以降は更新が起きません.上の例のように辺を見る順番が悪いと,実際に N − 1 周ぎりぎりまでかかることもあります.

負閉路の検出

逆に,N 周目になっても更新が起きるなら,どこかに始点から到達できる負閉路があります.負閉路を1周するごとに距離が小さくなるので,更新が止まらないからです.
このとき「最短距離」は −∞ になり,求めることができません.

なぜ $O(NM)$ なのか

1周で M 本の辺を1回ずつ見て,最大 N 周するので $O(NM)$ です.ダイクストラ法よりかなり遅いので,負の重みがないときはダイクストラ法を使います.

実装

上の図と同じグラフで,頂点 0 からの距離を求めます.負閉路があるときは None を返します.
後半では 4→1 に重み −1 の辺を足して,1→3→4→1 の重みの和を 2 − 2 − 1 = −1 にしています.

N = 5
# (u, v, w) : u から v へ重み w の有向辺
edges = [(3, 4, -2), (1, 3, 2), (2, 1, -3), (0, 2, 2), (0, 1, 4), (2, 4, 3)]

INF = float("inf")

def bellman_ford(s):
    dist = [INF] * N
    dist[s] = 0
    for i in range(N):
        updated = False
        for u, v, w in edges:  # すべての辺を見る
            if dist[u] != INF and dist[u] + w < dist[v]:
                dist[v] = dist[u] + w
                updated = True
        if not updated:  # 更新がなければ確定
            return dist
        if i == N - 1:  # N 周目でも更新された → 負閉路がある
            return None
    return dist

print(bellman_ford(0))
edges.append((4, 1, -1))  # 1 → 3 → 4 → 1 の重みの和が -1 になる辺を追加
print(bellman_ford(0))
[0, -1, 2, 1, -1]
None

注意点

  • dist[u] != INF の確認を忘れないようにします.∞ の頂点から緩和しないためです(float("inf") なら ∞ − 3 も ∞ なので結果は変わりませんが,INF を大きな整数にしているときは誤って更新されてしまいます).
  • 無向グラフで負の重みの辺があると,その辺を往復するだけで負閉路になってしまいます.負の重みは基本的に有向グラフで考えます.
  • この方法で検出できるのは始点から到達できる負閉路だけです.グラフのどこかに負閉路があるかを調べたいときは,すべての頂点の dist を 0 にして始めます.

負閉路の影響を受ける頂点を求める

負閉路があっても,そこから到達できない頂点の最短距離は普通に求まります.
「ゴールまでの最短距離が −∞ になるか」を知りたいときは,2N 周まわして,N 周目以降に更新された頂点の距離を −∞ にします.−∞ は負閉路から到達できる頂点に伝わっていくので,影響を受ける頂点がすべてわかります.

N = 6
edges = [(0, 1, 1), (1, 2, 1), (2, 1, -3), (2, 3, 1), (0, 4, 2), (4, 5, 2)]
INF = float("inf")

dist = [INF] * N
dist[0] = 0
for i in range(2 * N):  # 2N 周まわす
    for u, v, w in edges:
        if dist[u] != INF and dist[u] + w < dist[v]:
            # N 周目以降に更新される頂点は,負閉路の影響を受けている
            dist[v] = -INF if i >= N - 1 else dist[u] + w

print(dist)
[0, -inf, -inf, -inf, 2, 4]

1→2→1 が重みの和 −2 の負閉路なので,1, 2 とその先の 3 は −∞ になり,負閉路を通らない 4, 5 は普通に距離が求まっています.

ライブラリでの実装

AtCoder Library (ACL) にはベルマン-フォード法のライブラリはありませんが,SciPy の scipy.sparse.csgraph に bellman_ford があります.
負閉路があるときは NegativeCycleError という例外が発生します.

from scipy.sparse import csr_matrix
from scipy.sparse.csgraph import bellman_ford, NegativeCycleError

N = 5
edges = [(3, 4, -2), (1, 3, 2), (2, 1, -3), (0, 2, 2), (0, 1, 4), (2, 4, 3)]
row = [u for u, v, w in edges]
col = [v for u, v, w in edges]
data = [w for u, v, w in edges]
G = csr_matrix((data, (row, col)), shape=(N, N))
print(bellman_ford(G, directed=True, indices=0))

G2 = csr_matrix((data + [-1], (row + [4], col + [1])), shape=(N, N))
try:
    bellman_ford(G2, directed=True, indices=0)
except NegativeCycleError:
    print("negative cycle")
[ 0. -1.  2.  1. -1.]
negative cycle

SciPy の bellman_ford は負閉路があると例外を出して終わるので,上の「負閉路の影響を受ける頂点」のような処理が必要なときは自分で実装します.

ダイクストラ法との比較

ダイクストラ法ベルマン-フォード法
扱える重み0 以上負もOK
負閉路の検出できないできる
計算量$O((N + M) \log N)$$O(NM)$

負の重みがなければダイクストラ法,負の重みがある・負閉路を調べたいときはベルマン-フォード法を使います.
