Segment Tree（セグメントツリー）

区間クエリや更新が高速に行える木構造について解説します.

セグ木について

セグメントツリーは,配列に対する区間クエリと一点更新を $O(\log N)$ で行うことができる木構造です.
具体的には,ある区間の最小・最大値,和など,結合法則が成り立つ演算なら何でも取り扱うことができます.

操作計算量
区間クエリ$O(\log N)$
一点更新$O(\log N)$
区間更新(M個)通常 $O(M \log N)$,遅延評価セグメント木では $O(\log N)$

下図は A = [3,1,4,1,5,9,2,6] のときの最小値についての値を持つセグ木の例です.
サイズは2Nとなっており,上に行くにつれてより大きな区間の最小値を持つようになっています.

区間クエリの計算

上図の区間 [l, r) における最小値を求めることを考えます.
今回は,l=2, r=7, N=8, A[l:r]=[4,1,5,9,2], seg = セグ木とします.
また,暫定の最小値を ans に保存するため,十分に大きな値で初期化します.

L = l+N = 10, R = r+N = 15 とし,それぞれの葉にアクセスできるようにします.

  1. L=10, R=15, ans = inf
    Lは偶数なので,L = L//2 = 5 として親に移動.
    Rは奇数で範囲外のため,R = R−1 = 14 とし,ans = min(ans, seg[14]) = 2 とし,R = R//2 = 7
  2. L=5, R=7, ans = 2
    Lは奇数で親は使えないので,ans = min(ans, seg[5]) = 1 とし,L = L+1 = 6, L = L//2 = 3
    Rは奇数で範囲外のため,R = R−1 = 6 とし,ans = min(ans, seg[6]) = 1 とし,R = R//2 = 3
  3. L = R = 3 のため操作を終了.ans = 1

一点更新

一点更新は区間クエリとは異なり,比較的処理が簡単で直感的です.
A[1]の値を1から2に変更したいとします.
まず seg[9] = 2 とします.
次に親である seg[4] を,2つの子の値を用いて演算し更新します.seg[4] = min(seg[8], seg[9])
同様に seg[2], seg[1] を更新することで,一点更新の操作は $O(\log N)$ で完了することがわかります.

ライブラリでの実装

AtCoder Library (ACL) にはセグ木のライブラリが存在します.

from atcoder.segtree import SegTree

def op(x, y): # 演算関数の定義 (min, max, xor, 和など)
    return min(x, y)
e = float('inf') # 単位元の定義
a = [3,1,4,1,5,9,2,6] # 対象データを適宜設定

st = SegTree(op, e, a) # 初期化: SegTree(演算関数, 単位元, 配列)

print(st.prod(0, 3))  # 区間取得: prod(l, r) [0, 3) の最小値 -> 1

st.set(1, 2)         # 一点更新: a[1] を 2 に変更
print(st.prod(0, 3))  # [0, 3) の最小値
print(st.all_prod()) # 配列全体の取得
1
2
1

操作一覧

操作操作内容計算量
SegTree.prod(l, r)区間 [l, r) の演算結果$O(\log N)$
SegTree.all_prod()全体の演算結果$O(1)$
SegTree.set(i, x)元の配列Aの $A[i]$ を x に変更$O(\log N)$

prod は代数学における結合法則が成り立つ二項演算 ($a \circ b$) の結果を広く呼ぶ「積」(product) から来ています.
掛け算の積ではないです.

単位元について

単位元 e は,演算 op について「どんな x と組み合わせても x を変えない値」です.
つまり,すべての x について op(e, x) = op(x, e) = x が成り立つ値を指定します.
例えば min なら,どんな値と min をとっても相手がそのまま残る inf が単位元になります.

ACLのセグ木では,単位元は次のような場面で使われます.

  • 計算の初期値:区間クエリでは,答えを e で初期化してから区間内のノードを順に op で合わせていきます.上の「区間クエリの計算」で ans = inf から始めたのと同じです.
  • 空の区間の答え:prod(l, l) のように区間が空のときは e が返ります.
  • 配列の穴埋め:内部では配列の長さを2のべき乗に揃えるため,足りない部分の葉を e で埋めます.

単位元を間違えると答えが壊れます.例えば min なのに e = 0 にすると,初期値の 0 がどの値よりも小さいので,どの区間でも答えが 0 になってしまいます.

st = SegTree(min, 0, [3,1,4,1,5,9,2,6]) # 単位元を間違えた例
print(st.prod(2, 7)) # 本当の答えは 1
0

演算関数の例

op は結合法則 op(op(a, b), c) = op(a, op(b, c)) が成り立つ演算なら何でも使えます.
交換法則(op(a, b) = op(b, a))は必要ないので,文字列の連結のように順番に意味がある演算も扱えます.

求めたいものop単位元 e
区間の最小値min(x, y)float('inf')
区間の最大値max(x, y)-float('inf')
区間の和x + y0
区間の積(mod付き)x * y % MOD1
区間のxorx ^ y0
区間のorx | y0
区間のandx & y-1(全ビットが1)

区間の最小値とその位置min(x, y)(要素を (値, 添字) のタプルにする)(float('inf'), -1)
文字列の連結x + y(要素を文字列にする)""

op と e を差し替えるだけで,同じ配列に対していろいろな区間クエリができます.

from atcoder.segtree import SegTree
from math import gcd

a = [3,1,4,1,5,9,2,6]

st_sum = SegTree(lambda x, y: x + y, 0, a) # 和
st_max = SegTree(max, -float('inf'), a)    # 最大値
st_gcd = SegTree(gcd, 0, a)                # gcd
st_pos = SegTree(min, (float('inf'), -1), [(v, i) for i, v in enumerate(a)]) # 最小値とその位置

print(st_sum.prod(2, 7)) # 4+1+5+9+2
print(st_max.prod(2, 7))
print(st_gcd.prod(2, 7))
print(st_pos.prod(2, 7)) # (最小値, その添字)
21
9
