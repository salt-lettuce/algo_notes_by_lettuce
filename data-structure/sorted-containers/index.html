SortedContainers

高速に整列された入れ物を扱うことができるSortedContainersについて解説します.

参考：アルゴ式

SortedContainersについて

Pythonの標準ライブラリには,要素を常にソートされた状態で保つ集合(C++の std::set や std::multiset にあたるもの)がありません.
sortedcontainers を使うと,追加・削除をしながら「x以上で最小の値」や「k番目に小さい値」を高速に求めることができます.

クラス用途主な操作の計算量
SortedList重複ありのソート済みリスト(multiset)追加・削除・インデックスアクセス・二分探索 $O(\log N)$
SortedSet重複なしのソート済み集合(set)追加・削除・インデックスアクセス・二分探索 $O(\log N)$
SortedDictキー順に並んだ辞書(map)追加・削除・k番目のキー取得 $O(\log N)$

SortedList

重複を許すソート済みのリストです(C++の multiset に近い).
インデックスで k 番目の値を取り出せるのと,bisect_left / bisect_right で「x 以上で最小の値」などを探せるのが便利な点です.

from sortedcontainers import SortedList

sl = SortedList([5, 1, 3])
sl.add(3)              # 重複してもOK
print(sl)              # 常にソートされている
print(sl[0], sl[-1])   # 最小値と最大値
i = sl.bisect_left(4)  # 4 以上で最小の値の位置
print(sl[i])
sl.remove(3)           # 3 を1つだけ削除
print(sl)
SortedList([1, 3, 3, 5])
1 5
5
SortedList([1, 3, 5])

操作一覧

操作操作内容計算量
sl.add(value)要素 value を追加し,ソート状態を維持する$O(\log N)$
sl.discard(value)要素 value を削除する (存在しない場合もエラーにならない)$O(\log N)$
sl.remove(value)要素 value を削除する (存在しない場合は ValueError)$O(\log N)$
sl.pop(index=-1)index 番目の要素を削除して返す (デフォルトは末尾)$O(\log N)$
sl[index]index 番目の要素を取得する (ランダムアクセス)$O(\log N)$
value in slvalue が含まれているか判定する$O(\log N)$
sl.bisect_left(value)value 以上の要素が現れる最初のインデックスを返す$O(\log N)$
sl.bisect_right(value)value より大きい要素が現れる最初のインデックスを返す$O(\log N)$
sl.count(value)要素 value の個数を返す$O(\log N)$
sl.index(value)要素 value が最初に現れるインデックスを返す$O(\log N)$
len(sl)要素数を返す$O(1)$
sl.clear()全要素を削除する$O(N)$

SortedSet

重複を許さないソート済みの集合です(C++の set に近い).
普通の set と同じように使えて,さらに順番どおりに取り出したり二分探索したりできます.

from sortedcontainers import SortedSet

ss = SortedSet([5, 1, 3, 3])  # 重複は1つにまとまる
ss.add(2)
print(ss)
print(3 in ss)                # 含まれているか
i = ss.bisect_right(3)        # 3 より大きい最小の値の位置
print(ss[i])
ss.discard(1)                 # 削除
print(ss)
SortedSet([1, 2, 3, 5])
True
5
SortedSet([2, 3, 5])

操作操作内容計算量
ss.add(value)要素 value を追加する (重複は無視)$O(\log N)$
ss.discard(value)要素 value を削除する (存在しない場合もエラーにならない)$O(\log N)$
ss.remove(value)要素 value を削除する (存在しない場合は ValueError)$O(\log N)$
ss.pop(index=-1)index 番目の要素を削除して返す (デフォルトは末尾)$O(\log N)$
ss[index]index 番目の要素を取得する$O(\log N)$
value in ssvalue が含まれているか判定する$O(\log N)$
ss.bisect_left(value)value 以上の要素が現れる最初のインデックスを返す$O(\log N)$
ss.bisect_right(value)value より大きい要素が現れる最初のインデックスを返す$O(\log N)$
ss.index(value)要素 value のインデックスを返す$O(\log N)$

SortedDict

キーの順に並んだ辞書です(C++の map に近い).
普通の dict と同じように使えて,さらに最小・最大のキーや k 番目のキーを取り出せます.

from sortedcontainers import SortedDict

sd = SortedDict()
sd["banana"] = 3
sd["apple"] = 5
sd["cherry"] = 1
print(sd)               # キーの順に並ぶ
print(sd.peekitem(0))   # 最小のキーとその値
print(sd.peekitem(-1))  # 最大のキーとその値
print(sd.keys()[1])     # 小さい方から2番目のキー
SortedDict({'apple': 5, 'banana': 3, 'cherry': 1})
('apple', 5)
('cherry', 1)
banana

操作一覧

操作操作内容計算量
sd[key] = valueキーと値を設定する (キー順に自動ソート)$O(\log N)$
del sd[key]指定した key を削除する$O(\log N)$
sd.pop(key)指定した key を削除し,値を返す$O(\log N)$
sd.popitem(index=-1)ソート順で index 番目の (key, value) を削除して返す$O(\log N)$
sd.peekitem(index=-1)ソート順で index 番目の (key, value) を取得する (削除しない)$O(\log N)$
key in sdkey が含まれているか判定する$O(\log N)$
sd.keys()[index]ソート順で index 番目のキーを取得する$O(\log N)$
sd.values()[index]ソート順で index 番目の値を取得する$O(\log N)$
len(sd)キーの個数を返す$O(1)$
sd.clear()全要素を削除する$O(N)$
