SortedContainers

高速に整列された入れ物を扱うことができるSortedContainersについて解説していきます.

参考：アルゴ式

SortedContainersについて

Pythonの標準ライブラリには,要素を常にソートされた状態で保つ集合(C++の std::set や std::multiset にあたるもの)がありません.
sortedcontainers を使うと,追加・削除をしながら「x以上で最小の値」や「k番目に小さい値」を高速に求めることができます.

クラス用途主な操作の計算量
SortedList重複ありのソート済みリスト(multiset)追加・削除・インデックスアクセス・二分探索 O(logN)
SortedSet重複なしのソート済み集合(set)追加・削除・インデックスアクセス・二分探索 O(logN)
SortedDictキー順に並んだ辞書(map)追加・削除・k番目のキー取得 O(logN)

SortedList

from sortedcontainers import SortedList

sl = SortedList()
sl.add(3)
print(sl)
SortedList([3])

操作一覧

操作操作内容計算量
sl.add(value)要素 value を追加し,ソート状態を維持するO(logN)
sl.discard(value)要素 value を削除する (存在しない場合もエラーにならない)O(logN)
sl.remove(value)要素 value を削除する (存在しない場合は ValueError)O(logN)
sl.pop(index=-1)index 番目の要素を削除して返す (デフォルトは末尾)O(logN)
sl[index]index 番目の要素を取得する (ランダムアクセス)O(logN)
value in slvalue が含まれているか判定するO(logN)
sl.bisect_left(value)value 以上の要素が現れる最初のインデックスを返すO(logN)
sl.bisect_right(value)value より大きい要素が現れる最初のインデックスを返すO(logN)
sl.count(value)要素 value の個数を返すO(logN)
sl.index(value)要素 value が最初に現れるインデックスを返すO(logN)
len(sl)要素数を返すO(1)
sl.clear()全要素を削除するO(N)
